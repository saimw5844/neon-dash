# Neon Dash

An original HTML5 Endless Runner game.

Play it here after GitHub Pages is enabled: https://saimw5844.github.io/neon-dash/

## How to play

- **Jump / Double jump:** Space, Up arrow, or tap
- **Slide:** Down arrow or swipe down
- **Pause / Mute:** On-screen buttons

Collect coins (+25 points), dodge 5 types of obstacles including drones, and survive as the speed increases every 400m.

Built as a single-file HTML5 Canvas game — no installation needed, works on mobile and desktop.
